# My Philadelphia Eagles Website

A beginner-friendly website about the Philadelphia Eagles, made with HTML, CSS, and JavaScript.

## Files

- `index.html` contains the page and its three content sections.
- `style.css` adds the green and white colors and page layout.
- `script.js` changes the cheer message when the button is clicked.
- `images/football.svg` is the football picture used in the About section.

Open `index.html` in a browser to view the site. To publish it with GitHub Pages, upload the files to the root of a public repository and select **Settings → Pages → Deploy from a branch → main → /(root)**.
